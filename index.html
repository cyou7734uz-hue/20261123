桌寵使用方法

  1. 桌寵需要使用 Electron 桌面程式，直接用瀏覽器開啟網頁無法置頂顯示。
  2. 在 Windows 電腦安裝 Node.js 22.12 以上版本，並取得完整專案資料夾。
  3. 在專案資料夾開啟終端機，第一次使用先執行 npm install。
  4. 安裝完成後執行 npm start 開啟桌面程式。
  5. 點聊天視窗右上角的 ⚙️，選擇「啟動桌寵模式」。桌寵可拖曳移動，點 💬 可返回聊天。

首次安裝需要網路下載 Electron 執行檔（約 150 MB）。目前尚未提供安裝程式。
